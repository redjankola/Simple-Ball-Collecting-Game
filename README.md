# 🎮 Koshi Loja (Ball Catch Game)

A simple 2D Java Swing game where the player controls a basket ("koshi") to catch falling balls ("rrath"). The goal is to score as many points as possible while avoiding losing all lives.

---

## 🧩 Features

- 🎯 Catch falling balls to increase score
- ❤️ 5 lives system
- ⚡ Increasing difficulty as score grows
- ⏸ Pause and resume gameplay
- 🔄 Restart after game over
- 🎨 Smooth animations using Java Swing Timer (~60 FPS)
- 🎮 Keyboard controls

---

## 🕹 Controls

| Key | Action |
|-----|--------|
| ⬅️ Left Arrow | Move basket left |
| ➡️ Right Arrow | Move basket right |
| N | Pause game |
| R | Resume / Restart game |
| S | Exit game |
